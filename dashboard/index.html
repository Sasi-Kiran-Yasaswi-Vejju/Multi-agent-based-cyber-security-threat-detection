Academic Defense: Base Rate Fallacy in Cybersecurity

In enterprise networks, attacks often represent <1% of billions of raw packets. A naïve classifier guessing "NORMAL" on every packet achieves >99% accuracy while permitting total system compromise. Thus, Precision (100.0%) and False Positive Rate (0.00%) are the paramount operational metrics for SOC viability.

Algorithmic Formulation: A* Cost-Optimal Search vs Uninformed BFS

In response planning, selecting mitigation actions solely based on shortest hop count (BFS) causes catastrophic business downtime (e.g. prematurely powering down core infrastructure). Agent 4 utilizes A* Search with an Admissible and Consistent Heuristic:

Evaluation Function: f(n) = g(n) + h(n)
where g(n) = Cumulative Operational Cost along the current path,
and h(n) = min(step_cost) * remaining_steps to goal state.

Proof of Admissibility: Since h(n) is bounded by minimum edge weights (cost ≥ 1),
∀ n, h(n) ≤ h*(n) ⇒ A* is provably optimal and never overestimates actual cost.

Faculty Defense & Technical Viva Cheat-Sheet

Q1: Why use a Multi-Agent System rather than a single fine-tuned Large Language Model (LLM)?
Answer: Monolithic LLMs suffer from non-deterministic hallucinations, latency spikes (>1000ms), and lack formal verifiability in life-critical SOC operations. Our system employs a Neuro-Symbolic Multi-Agent architecture: fast statistical machine learning for reflex perception (Agent 1), formal CIA symbolic logic (Agent 2), graph algorithms over STIX/KEV (Agent 3), and provably optimal A* search (Agent 4). This guarantees sub-20ms latency and zero hallucination of security directives.
Q2: How do your agents communicate, and is the architecture purely a sequential pipeline?
Answer: The agents use a typed message-passing envelope protocol inspired by FIPA-ACL (ALERT, INTELLIGENCE_REQUEST, CLARIFICATION_REQUEST, FINAL_DECISION). It is not purely sequential: we implemented Smart Routing (Early Exit) which prunes downstream agents when traffic is benign (≥80% confidence, saving 75% computational cost), and a Backward Clarification Loop where Agent 4 queries Agent 2 when target asset context is missing.
Q3: Why is your A* heuristic admissible, and why does BFS fail in this context?
Answer: An admissible heuristic must satisfy $h(n) \le h^*(n)$. In our Response Graph, every mitigation transition incurs an operational cost $c \ge 1.0$. By defining $h(n) = \min(\text{edge\_cost}) \cdot \text{remaining\_hops}$, $h(n)$ can never exceed the true cost. BFS is blind to action costs; it treats dropping an IP the same as taking a critical core database offline because both take 1 hop. A* minimizes cumulative operational impact.
Q4: What dataset was used to evaluate Agent 1, and what are its known limitations?
Answer: Agent 1 was trained on network flow telemetry reflecting the CIC-IDS2017 benchmark. On test evaluation, it achieved 88.63% accuracy and 100% precision (0 false positives on 1,055 benign trials). However, we maintain academic integrity by acknowledging dataset limitations: synthetic lab traffic features cleaner boundaries than noisy real-world enterprise zero-days, which is precisely why Agent 2 and Agent 3 provide symbolic and KEV validation.
